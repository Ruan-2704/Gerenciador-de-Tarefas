Gerenciador de Tarefas - React

Arquivo principal:
- App.js

Funcionalidades:
- Adicionar tarefas
- Marcar tarefas como concluídas
- Filtrar por Todas, Concluídas e Pendentes
- Estado global com useContext + useReducer
- Estado local do campo com useState
- Atualização imutável do estado

Uso:
Substitua o App.js do seu projeto React por este arquivo.
Depois execute o projeto normalmente.
